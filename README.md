# What can I drive?

A Wausau Pilot & Review tool: enter what you earn and can put down, get a
sticker-price ceiling that includes Wisconsin sales tax, title, plates and the
Marathon County wheel tax, then see which vehicles in a local dealer's lot
fit under it — each with its own honest monthly payment.

See `CLAUDE.md` for architecture, the feed contract, and the swap-in steps
for a real dealer.
